# Label Sorter

Meesho & Flipkart label PDFs -> cropped labels, grouped by SKU. Runs 100% in the browser (no server, no upload).

## Run locally
    npm install
    npm run dev

## Deploy on Vercel
1. Push this folder to a GitHub repo
2. vercel.com -> Add New Project -> import the repo
3. Framework preset: Vite (auto-detected). Deploy. No env vars needed.
